# Examples

Three videos, produced by this project, with the inputs and the numbers that
made them. Nothing here is a mock-up: each `output.mp4` is the file the pipeline
delivered, and each `result.json` records what it actually measured — including
the cases where it came out imperfect.

| Example | Template | Preset | Requested | Delivered | Narration from |
| :--- | :--- | :--- | ---: | ---: | :--- |
| [01_explainer](01_explainer/) | `editorial_argument` | `popular_science` | 28 s | 28.4 s | hand-written |
| [02_data_story](02_data_story/) | `data_story` | `data_breakdown` | 30 s | see `result.json` | built-in rules |
| [03_product](03_product/) | `product_demo` | `product_walkthrough` | 30 s | see `result.json` | built-in rules |

Each folder holds:

```
prompt.txt      the topic, as typed
config.json     every option that was passed
thumbnail.png   a frame from the finished video
output.mp4      the delivered file
result.json     providers, durations, warnings, and how it was verified
```

## On the narration source

This repository was verified on a machine with **no LLM key configured**. That
means:

- **01_explainer** used narration written by hand and passed in through
  `request.script`. The pipeline reports `narration_source: "user"` and does not
  claim a model produced it.
- **02** and **03** used the built-in rule writer, so they report
  `narration_source: "rule"`.

None of them report `"llm"`, because none of them were. Presenting rule-written
copy as model output would be the easiest thing in this repository to fake and
the most damaging thing to get caught faking. The voice, the rendering, the
subtitles and the composition are real in all three.

To produce a gallery entry with `narration_source: "llm"`, configure a key
(`html-video setup`, or the wizard's step 2) and re-run the same config.

## Reproducing one

```bash
html-video generate "为什么本地 AI 很重要" \
    --template editorial_argument --writing-preset popular_science \
    --duration 28 --out ./out
```

Or from Python, which is how `01_explainer` was built:

```python
from html_video_workflow import create_video

result = create_video("为什么本地 AI 很重要", duration_sec=28,
                      template="editorial_argument",
                      writing_preset="popular_science")
print(result.video_path, result.duration_sec, result.narration_source)
```

## About the file sizes

The MP4s are a few megabytes each and are committed on purpose — a gallery
nobody can watch is not a gallery. Larger renders and the intermediate scene
PNGs are **not** committed; `docs/assets/demo.mp4` is the one that matters for
the README, and everything else is regenerated by the commands above rather than
stored.
